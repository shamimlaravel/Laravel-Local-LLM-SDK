Features

Multi-Driver Support

Ollama, LM Studio, AirLLMLlama, and OpenAI-compatible servers

Enterprise Security

Token hashing, rate limiting, request validation, audit logging

Intelligent Failover

Automatic fallback to healthy drivers when issues occur

Streaming Support

Real-time Server-Sent Events (SSE) for instant responses

Embeddings

Generate vector embeddings for semantic search and RAG

Tool Calling

Define and use tools/functions with LLMs
