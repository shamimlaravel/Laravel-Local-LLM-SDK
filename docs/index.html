Ollama

Most popular local LLM runtime for macOS, Linux, and Windows.

1. Install Ollama

# macOS / Linux
curl -fsSL https://ollama.com/install.sh | sh

# Windows (WSL)
# Install via above or download from ollama.com

2. Download Models

ollama pull llama3.2
ollama list

3. Start Service

# Ollama runs on http://localhost:11434
curl http://localhost:11434/api/tags

LM Studio

Desktop application for running LLMs locally with easy model management.

1. Download & Install

Download from lmstudio.ai

2. Start Server

Click "Start Server" in the UI (fourth icon on left sidebar)

# Default endpoint
http://localhost:1234/v1

llama.cpp

Pure C/C++ inference engine with CPU-first optimization and minimal dependencies.

✓ Strengths

  • • Zero external dependencies
  • • CPU & GPU acceleration
  • • Very low memory usage
  • • Mac/Windows/Linux

⚠ Considerations

  • • Command-line focused
  • • Requires model quantization

1. Install

# macOS
brew install llama.cpp

# Linux/Windows
pip install llama-cpp-python

2. Run Server

# Start HTTP server
./server -m model.gguf --port 8080

# Or use Python
python -m llama_cpp.server --model model.gguf

vLLM

High-throughput LLM inference engine with PagedAttention for efficient memory usage.

Best for: Production deployments, high-volume inference, KV cache optimization

✓ Strengths

  • • PagedAttention memory efficiency
  • • Continuous batching
  • • Tensor parallelism
  • • FP8 quantization support

⚠ Considerations

  • • NVIDIA GPU required
  • • Higher memory footprint

1. Install

# Docker (recommended)
docker pull vllm/vllm-openai:latest

# Or pip
pip install vllm

2. Start Server

docker run --runtime nvidia \
    --gpus all \
    -v ~/.cache/huggingface:/root/.cache/huggingface \
    -p 8000:8000 \
    --env HF_TOKEN=$HF_TOKEN \
    vllm/vllm-openai:latest \
    --model meta-llama/Llama-3.1-8B-Instruct

3. SDK Configuration

# .env
LLM_DEFAULT_DRIVER=openai-compatible
LLM_OPENAI_COMPATIBLE_URL=http://localhost:8000/v1
LLM_OPENAI_COMPATIBLE_MODEL=meta-llama/Llama-3.1-8B-Instruct

  • • Remove unnecessary context

  • • Set appropriate max_tokens
  • • Use temperature to control verbosity
  • • Enable stop sequences

Context SDK Usage

// Context Management Example
use LaravelLocalLlm\Services\ContextManager;

$manager = app(ContextManager::class);

// Sliding window approach
$messages = $manager->slidingWindow(
    messages: $chatHistory,
    maxTokens: 4096
);

// Summarization approach
$messages = $manager->withSummarization(
    messages: $chatHistory,
    summaryModel: 'llama3.2'
);

// RAG approach
$messages = $manager->withRAG(
    query: $userMessage,
    maxTokens: 2048
);

// Hybrid approach
$messages = $manager->optimize($messages, [
    'strategy' => 'hybrid',
    'max_tokens' => 8192,
]);

Custom Driver

Create your own driver for unsupported LLM servers.

Extend BaseDriver

use LaravelLocalLlm\Drivers\BaseDriver;

class MyCustomDriver extends BaseDriver
{
    public function chat(ChatRequest $request): ChatResponse
    {
        $response = $this->client->post('/api/chat', [
            'json' => $request->toArray()
        ]);
        
        return new ChatResponse(
            content: $response['choices'][0]['message']['content'],
            // ... other fields
        );
    }
}

Register Driver

// config/llm.php
'drivers' => [
    'custom' => [
        'driver' => \App\Drivers\MyCustomDriver::class,
        'url' => env('LLM_CUSTOM_URL'),
    ],
],

Basic Usage

Using the Facade

use LaravelLocalLlm\Facades\LocalLlm;
use LaravelLocalLlm\DTO\Message;

$response = LocalLlm::chat(
    new ChatRequest(
        model: 'llama3.2',
        messages: [Message::user('Hello!')]
    )
);

echo $response->content;

Using the Builder

$response = LocalLlm::chatWithBuilder()
    ->model('llama3.2')
    ->withUserMessage('Hello!')
    ->temperature(0.7)
    ->send();

echo $response->content;

Streaming Responses

LocalLlm::chatWithBuilder()
    ->model('llama3.2')
    ->withUserMessage('Tell me a story')
    ->stream(true)
    ->sendStream(function ($chunk) {
        echo $chunk->content;
        
        if ($chunk->finished) {
            echo "\nDone!\n";
        }
    });

Embeddings

use LaravelLocalLlm\Facades\LocalLlm;
use LaravelLocalLlm\DTO\EmbeddingRequest;

$response = LocalLlm::embeddings(new EmbeddingRequest(
    model: 'text-embedding-3-small',
    input: 'Hello world'
));

$embedding = $response->embeddings[0]->embedding;

Batch Processing

use LaravelLocalLlm\Facades\LocalLlm;
use LaravelLocalLlm\DTO\BatchChatRequest;
use LaravelLocalLlm\DTO\ChatRequest;
use LaravelLocalLlm\DTO\Message;

$requests = [
    new ChatRequest(model: 'llama3.2', messages: [Message::user('Hi')]),
    new ChatRequest(model: 'llama3.2', messages: [Message::user('Hello')]),
];

$batch = LocalLlm::batchChat(new BatchChatRequest($requests));

echo "Total: " . $batch->count() . " requests\n";
echo "Tokens: " . $batch->totalTokens() . "\n";
echo "Avg latency: " . $batch->averageLatencyMs() . "ms";

Tool Calling

Define Tools

use LaravelLocalLlm\Tools\CallableTool;
use LaravelLocalLlm\Tools\StringParameter;

$tools = [
    new CallableTool(
        name: 'get_weather',
        description: 'Get weather for location',
        parameters: [new StringParameter('location', 'City name')],
        handler: fn($args) => "Weather: 22°C"
    )
];

Use with Chat

$response = LocalLlm::chatWithBuilder()
    ->model('llama3.2')
    ->withUserMessage('Weather in Paris?')
    ->withTools($tools)
    ->send();

foreach ($response->toolCalls as $call) {
    $result = $call->execute();
}

🔐 Token Management

Create Token

$token = LlmToken::create([
    'name' => 'Production API',
    'hashed_token' => TokenHasher::make('secret'),
    'abilities' => ['chat', 'stream', 'embeddings'],
    'rate_limit' => 100,
    'monthly_quota' => 1000000,
]);

Validate Token

$guard = app(TokenGuard::class);
$token = $guard->validate('secret-token');

if ($guard->checkAbilities($token, ['chat'])) {
    // Authorized
}

Configure Rate Limits

// Global config
'rate_limit' => [

    'window' => 60,     // seconds

$limiter = app(LlmRateLimiter::class);

if (!$limiter->check($token)) {
    return response()->json([
        'error' => 'Rate limit exceeded'
    ], 429);
}

🔌 Circuit Breaker Pattern

Protect your application from cascading failures by opening the circuit when a service is unhealthy.

Request
→
Circuit Gate
→
CLOSED
Closed: Normal operation Open: Failing fast Half-Open: Testing recovery

Configuration

// config/llm.php
'circuit_breaker' => [
    'enabled' => true,
    'failure_threshold' => 5,  // Open after 5 failures
    'success_threshold' => 2,  // Close after 2 successes
    'timeout' => 30,           // Seconds before half-open
],

Usage

$breaker = app(CircuitBreaker::class);

$result = $breaker->call(function() {
    return $driver->chat($request);
});

// Check circuit state
if ($breaker->isOpen()) {
    // Return fallback immediately
}

📋 Request Queue

Queue requests for batch processing or rate limiting.

Enqueue Request

$queue = app(LlmRequestQueue::class);

// Add to queue
$jobId = $queue->enqueue(
    new ChatRequest(...),
    ['priority' => 'high']
);

// Get status
$status = $queue->status($jobId);

Process Queue

// In console command or queue worker
$queue->process(function($job) {
    $result = LocalLlm::chat($job->request);
    $job->complete($result);
});
