## [1.0.0-beta] - Unreleased

- Multi-driver architecture (Ollama, LM Studio, OpenAI-compatible)
- Auto-detection of available LLM drivers
- Intelligent failover system with health checks
- Streaming support (Server-Sent Events)
- Token-based authentication with rate limiting
- Monthly quota enforcement
- Usage tracking and analytics
- Builder pattern for fluent API
- Event-driven architecture
- Tool calling abstraction
- Prompt template engine
- Retry engine with exponential backoff
- GitHub Actions CI workflow
- Comprehensive unit tests
- PHPStan configuration (level max)
- Pint code style configuration
- Type safety checklist for contributors
